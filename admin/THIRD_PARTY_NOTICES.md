# Third party notices

The UI uses generated shadcn components and an unchanged shadcn 4.21.0 stylesheet.
The stylesheet is vendored to avoid requiring the component-generator CLI and
its dependency graph during application builds. Its MIT notice is distributed
at `public/licenses/shadcn.txt`.

Geist font assets retain the SIL Open Font License distributed at
`public/licenses/geist.txt`. Other npm dependencies retain their own licenses;
the lockfile identifies exact versions. Built browser assets retain dependency
license comments where the bundler emits them.
